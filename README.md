# Math Up

Workspace untuk guru matematika: dashboard, jadwal mengajar, To-Do, kalender akademik, Drive materi, dan kolaborasi guru.

## Status
Fondasi UI dan interaksi dashboard sudah dibuat. Data contoh saat ini masih lokal di browser.

## Rencana integrasi
- Google Sign-In
- Google Sheets untuk Users, Teachers, Schedule, Todo, Events
- Google Drive untuk materi
- Kalender nasional Indonesia + agenda sekolah
- Deployment via GitHub/Vercel

## Keamanan
Jangan commit OAuth client secret, service-account JSON, token, password, atau credential Google apa pun ke repository publik. Gunakan environment secrets.
